# AI 伺服器料件資料字典（PartsQA）

> 本資料集為**虛構的範例資料**，由 `scripts/generate_sample_data.py` 以固定亂數種子產生，用於展示資料清理與料件問答系統。
> 料號、供應商代號（`V-xx`）、數量與價格皆非真實資料。領域設定（檔名、料號格式、產品線、工廠、物料類別、基準日）集中在 `config/domain.json`。

## 1. 檔案

| 檔案 | 內容 |
|---|---|
| `item_master.csv` | 料號主檔（成品 FG、半成品 SA、原材料 RM） |
| `item_specs.csv` | 材料規格屬性（直式：一列一個屬性） |
| `bill_of_materials.csv` | 多階 BOM（含版次與生效區間） |
| `substitutes.csv` | 替代料主檔 |
| `stock_lots.csv` | 各廠庫存（批號層級），快照日 2026-09-30 |
| `purchase_orders.csv` | 採購單明細（含已結案、已取消） |

- 編碼為 UTF-8，第一列為欄位名稱，缺值以空白表示。
- 資料**刻意含有品質問題**，使用前需依本文件清理；檔案間以**料號**串接。

## 2. 計算基準

- **資料基準日：2026-09-30。** 庫存與採購單為當日快照。
- BOM 生效、替代料有效期、保存期限與在途到貨，一律以**生產日**判斷；指定一段期間（例如「11 月 1 日以後的生產」）時，以該期間的起始日為生產日；未指定生產日時，以基準日判斷。
- 半成品（SA）不留庫存，計算需求時一律展開到原材料（RM）。

## 3. 料號格式與標準化

| 類型 | 格式 | 範例 | 說明 |
|---|---|---|---|
| 成品 FG | `FG` + 產品線字母（`S`/`E`）+ 3 位機型代號 + `-` + 2 位版本 | `FGS208-01` | `S` 為資料中心伺服器（SRV），`E` 為邊緣運算主機（EDGE） |
| 半成品 SA | `ASY-` + 5 位數字 | `ASY-10001` | 自製（MakeBuy = `M`） |
| 原材料 RM | 3 碼物料類別 + `-` + 6 位數字 | `GPU-100801` | 類別碼見第 5 節 |

標準化規則（所有檔案的料號欄位皆適用）：
1. 去除頭尾空白、全形字元轉半形、英文字母轉大寫。
2. `–`、`—`、`－` 等破折號一律轉為 `-`。
3. 標準化後仍不符上表格式者為**無效料號**，不得猜測修正（例如把英文字母 `O` 當作數字 `0`）。
4. 在其他檔案出現、但料號主檔中不存在的料號，視為孤兒資料。
5. **產品線一律以成品料號判定**（`FGS` = SRV，`FGE` = EDGE）；主檔 `ProductLine` 欄位與料號不一致時，以料號為準並列入清理報告。

## 6. 材料屬性與單位

| AttrCode | 標準單位 | 說明 |
|---|---|---|
| Capacitance | µF | 電容值 |
| Resistance | Ω | 電阻值 |
| Inductance | µH | 電感值 |
| RatedVoltage | V | 額定電壓 |
| RatedCurrent | A | 額定電流 |
| PowerRating | W | 額定功率（GPU、CPU、電源的功耗等級亦記在此） |
| Tolerance | % | 誤差，`±1%` 視為 1 |
| TempMin／TempMax | °C | 最低／最高工作溫度 |
| MSL | 無 | 濕敏等級 |
| ShelfLifeMonths | 月 | 保存期限；**有此屬性的料號才需檢查效期** |
| Package | 文字 | 封裝或規格（例如 `SXM5`、`RDIMM-288`）；比對時忽略大小寫、空白與 `-` |
| RoHS | `Y`／`N` | 不分大小寫；其他寫法視為缺值 |
| SafetyCert | 文字清單 | 以 `;` 分隔；比對時忽略大小寫與空白 |

- 數值可能帶單位或 SI 字首（p、n、µ/μ/u、m、k/K、M），也可能使用 `Ω`、`ohm`、`℃`、`−`（Unicode 減號）等寫法，須換算為標準單位。電阻值只寫 `k`/`K`/`M` 時視為 kΩ/MΩ。
- AttrValue 只有數字、Unit 也空白時，視為該屬性的標準單位。
- 無法換算的值（如 `TBD`、`N/A`、單位與屬性不符）視為缺值。
- 同一料號、同一屬性有多筆資料：換算後相同視為重複；不同則**待人工確認**，確認前該屬性視為缺值。

## 8. BOM 規則

1. **生效判斷**：`EffectiveFrom ≤ 生產日 ≤ EffectiveTo` 的行才納入展開；版次（BOMRev）不作為判斷依據。
2. **單位換算**：BOM 用量須換算為下階料號主檔的單位：`KPCS` = 1,000 `PCS`、`EA` = `PCS`、`CM` = 0.01 `M`、`MM` = 0.001 `M`。無法換算（例如主檔為 `PCS`、BOM 為 `MM`）的行為無效行。
3. **需求計算**：毛需求 = 生產數量 × 各階（用量 × (1 + 損耗率)）的連乘，依原材料彙總；`PCS` 無條件進位到整數，`M` 無條件進位到小數第二位。
4. **損耗率**：空白為 0；帶 `%` 的百分比須換算為小數；沒有 `%` 的數值一律視為小數（例如 `5` 就是 5，不視為 5%）；不在 0～0.2 範圍或無法判讀者，以 0 計算並列入清理報告（本規則是唯一允許的預設值）。
5. 用量不是大於 0 的數字、日期無效、失效日早於生效日、上階或下階料號無效或不存在者，該行為無效行。
6. 所有欄位完全相同的行視為重複；同一上階、版次、行號卻內容不同者為**待人工確認**，確認前不展開。
7. 形成循環參照（A 用到 B、B 又用到 A）的行為**待人工確認**，不得展開。

## 9. 替代料規則

一筆替代料紀錄要能用在「某個成品 → 某個直接上階 → 某個主料」的位置，必須**同時**符合以下全部條件：

| 編號 | 規則 |
|---|---|
| A1 | `ApprovalStatus` 為 `Approved`。`Pending` 須經負責**主料**所屬物料類別的 R4 核准後才可使用；`Rejected` 不可使用。 |
| A2 | 生產日落在 `ValidFrom`～`ValidTo` 之間。 |
| A3 | **方向**：紀錄只代表「主料可由替代料取代」。反向使用僅限 `Bidirectional = Y`，此時用量比為 1 ÷ `QtyRatio`。 |
| A4 | **不得串接**：A→B 與 B→C 均有效，不代表 A→C 有效；A→C 須有自己的紀錄。 |
| A5 | **範圍**：`GLOBAL` 不限；`PRODUCTLINE` 限該產品線的成品；`PARENT` 限主料的**直接上階**為 ScopeValue。 |
| A6 | 替代料的生命週期須為 `Active` 或 `NRND`。 |
| A7 | **屬性相容**（替代料相對於主料）：RatedVoltage、RatedCurrent、PowerRating 不得較低；TempMin 不得較高、TempMax 不得較低；Tolerance 不得較大；`QtyRatio = 1` 時 Capacitance、Resistance、Inductance 須相同；Package 須相同；RoHS 須為 `Y`；SafetyCert 須涵蓋主料的所有認證。主料有、替代料缺值的屬性視為不符。 |
| A8 | **用量**：替代料用量 = 主料用量 × `QtyRatio`。 |
| A9 | **不可混用**：`MixAllowed = N` 時，同一個上階組件（例如同一片主機板）的該位置只能全用主料或全用替代料。 |
| A10 | **成組替代**：`BundleID` 相同的紀錄必須在同一個上階組件中一起切換；任一成員不可用，整組都不可用。 |
| A11 | 主料與替代料相同、用量比無效、日期無效或顛倒、範圍值無效者為無效紀錄；同一組主料、替代料、範圍與範圍值有多筆內容不同的紀錄者為**待人工確認**。 |
| A12 | 同一主料有多個可用替代料時，依 `Priority` 由小到大使用。 |

## 10. 庫存與在途規則

1. **可用庫存** = 每一批的（在庫量 − 保留量）加總，且該批須同時符合：
   - 工廠代碼有效，`QCStatus` 為 `合格`；
   - 單位換算後與主檔一致（`KPCS` × 1,000）；
   - 料號有 `ShelfLifeMonths` 時：以 DateCode 該 ISO 週的星期一為製造日，加上保存月數為到期日，**到期日早於生產日**則不可用；DateCode 無效者無法確認效期，亦不可用。
     - 週別在該 ISO 年不存在（例如 2025 年沒有第 53 週）的 DateCode 視為無效。
     - 加上保存月數後，若該月沒有同一天，以該月最後一天為到期日。
2. 在庫量為負數或非數字、保留量大於在庫量的批次為無效資料。
3. **在途採購**只計 `Status = Open` 的未交量（訂購量 − 已收量），且 `ETA + 3 天（進料檢驗）≤ 生產日`。ETA 無效者不計入。
   - **ETA 早於下單日（OrderDate）**的採購單項次為日期矛盾的無效資料，一律排除，不計入在途。
4. 日期只接受 `YYYY-MM-DD`、`YYYY/MM/DD`、`YYYYMMDD` 三種格式；其他寫法（如 `MM/DD/YYYY`、`DD-MM-YYYY`）**即使可推測也一律視為無效**。

## 11. 無效值處理原則

- 不在合法範圍內、或無法依本文件判定的值，視為缺值；計算需要該欄位時排除該筆資料，並在回答中說明排除筆數。
- 不得自行推估或補值（第 8 節損耗率除外）。
- 有允許值清單的欄位（例如 QCStatus、Lifecycle、ApprovalStatus、Status），只接受清單內的值（比對前先去除頭尾空白；欄位說明寫明「不分大小寫」者另忽略大小寫）；清單以外的寫法（例如 QCStatus 的 `OK`、`PASS`，Lifecycle 的 `量產`，ApprovalStatus 的 `核准中`）一律視為無效，不得自行對應。
- 標示為「待人工確認」的資料，須由負責該物料類別的 R4 零件工程師確認後才可使用。
- 料號主檔同一料號有多筆內容不同的紀錄時，該料號為**待人工確認**；確認前，其他檔案中與該料號相關的列也暫不使用。
- 所有欄位完全相同的列視為重複，只保留一筆。

## 12. 角色與權限（系統使用）

| 角色 | 資料範圍 | 一般 | 敏感 | 高度敏感 | 替代料核准 |
